# Rato brand

The Rato logo: the "O" of RATO is a camera lens (navy ring, leaf-green glass, six aperture
blades and a glint). Colours are the app's own: navy `#14284F`, leaf `#9BC45A`.

| File | Use |
| --- | --- |
| `rato-logo.svg` / `.png` | Full logo with "PHOTO BOOTH", on light backgrounds |
| `rato-logo-white.svg` / `.png` | Full logo on dark backgrounds (navy, photos) |
| `rato-wordmark.svg` / `.png` | The name alone |
| `rato-icon.svg` / `.png` | App icon, favicon, profile picture (1024 x 1024 PNG) |

The SVGs are outlines (Plus Jakarta Sans ExtraBold / Bold), so they look the same without
the font installed. `source/` holds the scripts that drew them.
