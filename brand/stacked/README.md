# Rato - stacked icon

RA / TO stacked in white on a rounded tile with a soft navy -> teal -> lime gradient.

| File | Use |
| --- | --- |
| `rato-stacked.svg` / `.png` | The icon as in the reference (1024 x 1024 PNG) |
| `rato-stacked-lens.svg` / `.png` | The same with the O as a camera lens |
| `preview.png` | Both, at several sizes and on light and dark |

Letters are Plus Jakarta Sans ExtraBold outlines. `source/make.py` draws the SVGs;
`source/export.mjs` renders the PNGs.
