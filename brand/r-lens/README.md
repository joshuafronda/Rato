# Rato - R with a lens

A monogram: a geometric **R** whose round bowl is a camera lens (holographic glass, six
aperture blades, a white glint), in the holographic palette of the camera logo.

| File | Use |
| --- | --- |
| `r-icon.svg` / `.png` | App icon: glowing holographic tile with a white R (1024 x 1024 PNG) |
| `r-mark.svg` / `.png` | The R alone in deep indigo, for light backgrounds |
| `r-mark-white.svg` / `.png` | The R alone in white, for dark backgrounds |
| `r-logo.svg` / `.png` | R + RATO + PHOTO BOOTH, on light backgrounds |
| `r-logo-white.svg` / `.png` | The same on dark backgrounds |
| `preview.png` | All of them together |

The R is drawn geometrically; RATO and PHOTO BOOTH are Plus Jakarta Sans outlines, so no
font is needed. `source/make.py` draws the SVGs; `source/export.mjs` renders the PNGs.
